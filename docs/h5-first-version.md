# 如期手记 H5 单机版

## 开发与发布

沿用 uni-app / Vue 3 / TypeScript / Pinia。使用 Node 22+ 和 pnpm 10.10.0。

```sh
pnpm install
pnpm dev:h5       # http://localhost:9000
pnpm check        # 类型、Lint、测试
pnpm build:h5     # dist/build/h5
pnpm build:mp
pnpm build:app
```

直接在 `master` 开发和提交，通过检查后推送，GitHub Pages 自动发布到 https://fengxiaopeng.github.io/timelynote-uniapp/ 。H5 使用 hash 路由，静态图标支持仓库子路径。

## 记录流程

底栏显示「首页、如期、＋、手记、我的」。保留原有布局与配色，如期使用闹钟图标，手记使用日历图标。中央「＋」直接进入新增手记；新增纪念日保留在如期页右上角。

- 随手记独立保存日常：文字、可选标题、日期、照片、人物、标签、可选地点。点击编辑页右上角日期即可修改，表单不再显示单独的发生日期行，并移除「不必特别，一句话也很好」副标题。天气属性已移除，不再提供关联纪念日入口，也不再接受 URL 中的 `eventId` 来建立新关联。
- 人物直接以头像与下方名字点选，点一下选中，再点取消，不需要进入选择面板或点击完成。编辑页人物与标签各自单行横向滑动，右侧固定「添加」「新建」入口。生日主人的关联不可取消；归档人物仅在已选时显示。现场新增人物后自动选中，并保留正在填写的内容。
- 普通标签直接点选，支持在输入框现场新建。新标签自动选中，同一手账中的纪念日和手记共用标签库。名称最多 20 个字，去除两端空格和多余空格，同名（英文不区分大小写）复用。
- 纪念日本身保存名称、日期、重复、提醒、人物，以及独立的文字、照片和标签。详情里的「丰富这一天」进入该纪念日编辑页并定位到内容区域，不新建手记。
- 纪念日详情可以预览照片并展示文字、标签；纪念日搜索包括标签。个人照片统计包含纪念日和手记的照片。
- 手记照片入口为并排的「选一张照片」和「拍一张照片」，相册可多选，相机一次拍一张。H5 触屏设备优先通过带 `capture="environment"` 的图片输入调用系统相机，单次拍摄一张；桌面端保留摄像头预览，可拍摄或取消，权限拒绝、设备不可用时提供重试与系统相机入口。系统是否遵循拍摄提示由浏览器决定。图库入口直接调用图片选择；iPhone Safari 可能仍展示系统的「照片图库 / 拍照 / 选取文件」菜单，网页不能强制跳过。只请求视频，不打开麦克风；拍摄、关闭、离开页面或等待权限期间取消后，都会释放相机资源。相机预览需要 HTTPS 或 localhost，系统相机能否直接唤起由浏览器与设备支持决定。
- 照片最多六张，选择与拍摄共用压缩规则，保存为 JPEG data URL，可移除、预览。单条记录的照片总量受本地配额限制，失败会提示并保留输入。
- 随手记「稍后」可以保存一篇草稿或放弃修改；替换已有草稿前确认。删除和备份覆盖前也会确认。

## 手记视图与列表筛选

手记页右上角使用紧凑菜单切换「默认 / 相册 / 日历」，当前选项以朱砂色勾选。每次重新加载从默认视图开始；查看详情后返回保留当前视图。移除手记页右上角搜索、新增按钮，以及「全部手记 / 有照片 / 按月份」一行，新增仍通过底栏「＋」。

- 默认：保留原有时间流卡片，顶部展示「标签」与「重要的人」两组 tag。两组清空项均显示「全部」，每组单行横向滑动，不随标签数量增加而换行。
- 相册：仅展示带照片的手记，照片居中、标题和文字在下方；标题居左、日期同排靠右，多图左右滑动并显示页码与圆点，点击照片可预览，点击文字打开详情。纯文字手记继续在默认视图和日历中显示。
- 日历：按手记的发生日期标记有记录的日期，点击日期查看当天记录与篇数；支持前后月份和月份选择器，点击记录打开详情。

相册与日历隐藏标签和人物筛选，相册展示所有带照片的记录，日历展示全部记录；切回默认恢复原先的筛选选择。三种视图共用同一份手记数据，不新增存储格式。相册每页 10 条，日历当天记录每页 20 条，通过本地分页追加。

手记默认视图和如期页的人物筛选显示头像与下方名字，可点选、再次点击取消。「全部标签」「全部人物」各自清空一组条件。组内任一匹配，两组之间同时匹配；如期页还可与关键词和纪念日分类组合查询。归档人物也可用于回看历史记录。筛选变化时重置本地分页，避免重复或残留结果。

## 重要的人与生日

入口为「我的 → 重要的人」。人物是个人手账中的记录对象，不是应用成员，不产生共享访问权限。

- 资料包括称呼、可上传头像、可选生日和备注，不再设置关系。列表移除搜索与归档切换，统一显示既有人物；旧归档资料继续可见。人物头像可进入人物回看页，聚合其纪念日与手记。
- 头像上传单张照片，压缩至最长边 256 像素，保存在本机并随备份导出；可更换、移除，默认展示称呼首字。手记和纪念日的编辑、详情、列表及人物筛选均显示头像和下方名字；编辑仍单行横向滑动，点选关联，生日主人不可取消。
- 人物生日可以不填，新增或修改仅选择完整公历年月日，不提供仅月日模式。旧的仅月日生日保留原值并提示补全年份；未重新选择日期时不猜测年份，也不因修改头像而覆盖旧生日。
- 设置生日会创建年度生日纪念日；已有生日关联会继续复用，保留标题、提醒和历史内容。
- `Person.birthdayEventId` 指向生日纪念日，日期只存在该事件上；`birthdayPersonId` 为反向关联。两个入口修改同一条记录。未知年份配合 `yearUnknown` 使用内部闰年基准，不展示为真实出生年份。
- 公历 2 月 29 日在非闰年按 2 月 28 日纪念，闰年恢复 2 月 29 日。
- 清空人物生日时，可选择保留或删除原纪念日。删除生日纪念日会同步清空人物生日，历史手记保留。
- 旧归档标记仅作兼容保存，界面不再提供归档分类或操作；删除人物仅解除人物关联，纪念日和手记保留。

## 登录、数据与备份

「我的 → 登录」使用符合大陆手机号格式的号码和固定验证码 **9999**；获取验证码展示重发倒计时，不发送短信、不验证手机号归属、不创建服务端 token。

游客和各手机号各自保存本地手账、人物与标签库。登录不会搬运游客数据，退出不会删除账号手账。模拟身份不构成真实认证或隐私安全隔离。

备份导出使用 v4，同时兼容导入 v1/v2/v3/v4：

- 旧人物补空头像并移除关系字段，头像格式和大小在迁移与备份导入时校验。
- 旧记录、照片、人物、标签和草稿保留；已弃用的天气字段在迁移时移除。
- 旧纪念日补空照片和标签，旧手账补标签库，并收录既有记录使用过的标签。
- 旧手记的 `anniversaryId` / `occurrence` 仅为历史兼容保留，在纪念日详情以「以往的手记」展示。新手记不再建立关联，已有记录的日期和正文不会被迁移改写。
- 导入时验证结构、照片格式、人物及生日双向关联；无效备份不会覆盖当前数据。
- 数据保存在当前浏览器，清理站点数据前应导出备份；备份不包含登录会话。

## 分层和 API 接入位置

| 层           | 位置                                                                                                       | 职责                                                                                     |
| ------------ | ---------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 页面         | `src/pages/journal/`、`src/pages/people/`                                                                  | 内容展示和表单，不直接操作浏览器存储                                                     |
| 手记呈现     | `src/pages/journal/components/NotesWorkspace.vue`、`NoteViewMenu.vue`、`NoteAlbum.vue`、`NoteCalendar.vue` | 页面协调、视图切换、相册和日历展示，复用仓储与状态层                                     |
| 公共编辑控件 | `src/components/fg-person-picker/`、`fg-tag-picker/`、`fg-photo-picker/`                                   | 直接点选人物、普通标签和照片，统一交互                                                   |
| 状态与用例   | `src/store/journal.ts`                                                                                     | 记录、人物、标签操作；串行事务防止新增标签与保存内容并发时互相覆盖；持久化成功后更新状态 |
| 领域规则     | `src/domain/journal.ts`、`people.ts`、`tags.ts`、`note-views.ts`                                           | 模型、迁移、校验、生日联动、标签规范化、手记日期分组与月历计算                           |
| 仓储         | `src/repositories/journal.ts`                                                                              | 异步 load/save，通过 Pinia 插件持久化，写后确认并在失败时回滚                            |
| 登录         | `src/api/journal/auth.ts`、`src/store/local-session.ts`                                                    | 可替换的模拟登录网关与本地身份                                                           |
| H5 平台接缝  | `src/utils/journal-media.ts`、`journal-camera.h5.ts`、`journal-backup.ts`                                  | 图片压缩、相机生命周期与备份，浏览器相机通过 H5 条件编译隔离                             |
| 视觉令牌     | `src/style/journal-tokens.css`                                                                             | 保留原型令牌名、暖纸与朱砂色值                                                           |

后端接入时，用走 `src/http` 的适配器替换仓储和登录网关。将模拟身份替换为真实 token 认证，再扩展实体 CRUD、照片上传和服务端分页；页面与领域规则继续复用。

## 首版边界和验证

当前只验收 H5；小程序和 App 做编译检查，尚未进行真机验收。提醒只保存偏好，不发送系统通知。未接入真实短信、云同步、农历、协作、图片/链接分享、PDF 或回收站。

自动化测试覆盖头像校验、人物迁移与生日关联保留，以及月历起始星期与闰年、跨年月切换与月末日期钳制、手记按发生日期分组，以及日期、人物生日、标签规范化、旧数据迁移、仓储恢复与失败回滚、账号隔离以及并发写入。浏览器验证三种视图切换、相册滑图、日历选日和详情返回、筛选恢复、320px 小屏布局，以及人物直接点选、标签与人物组合筛选、底栏直达、日期编辑、快捷新增、标签复用、纪念日内容、取消编辑、刷新、备份和手机布局。相机通过浏览器模拟摄像头验证拍摄及释放资源；手机系统相机与设备权限仍需真机验收。发布前执行 `pnpm check` 和构建验证。
