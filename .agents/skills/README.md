# 项目 Skills

所有技能统一放在本目录，按任务读取对应的 `SKILL.md`，不一次性加载全部资料。

| Skill | 用途 |
|---|---|
| `uni-app` | uni-app 框架、条件编译、页面与应用配置 |
| `uniapp-project` | 内置组件、uni-ui 与 API 示例 |
| `uniapp-mini-guide` | 小程序平台配置与兼容性 |
| `uniapp-native-app` | Android / iOS 原生打包、签名与证书 |
| `uniapp-native-plugin` | 原生插件开发 |
| `uniapp-plugin` | 插件市场与第三方插件集成 |
| `uniapp-project-creator` | uni-app 项目创建 |
| `uniapp-ucharts` | uCharts 图表 |
| `uniapp-ad` | 广告集成 |
| `uniapp-uview` | uView 组件库 |
| `uview-pro-vue3` | uView Pro（Vue 3）组件库 |
| `uniappx-project` | uni-app-x（UTS）组件与 API |
| `uniappx-project-creator` | uni-app-x 项目创建 |
| `uniappx-uview-pro` | uni-app-x 的 uView Pro 组件库 |

本项目使用 uni-app + Vue 3 + Wot UI。uView、uni-app-x 等技能仅在明确涉及对应技术时使用。云开发技能已移除。
